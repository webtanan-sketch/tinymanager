TinyManager — Windows Portable
==============================

1) Run Start-TinyManager.cmd.
2) TinyManager opens in your default browser on localhost.
3) No Node.js or Python installation is required.
4) TinyManager data stays in your browser's local IndexedDB storage.
5) Keep the localhost origin/port unchanged to preserve the same browser data origin.

For a normal Windows installation with shortcuts and upgrade support, use TinyManager-Setup.exe from GitHub Releases.
